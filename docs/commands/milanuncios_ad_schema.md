## milanuncios ad schema

Inspect JSON Schema Draft-07 publication contract for a category

### Synopsis

Retrieve the JSON Schema Draft-07 publication contract for a category.

Maps required fields, types, constraints and dynamic taxonomy filters under 'attributes'.

```
milanuncios ad schema [flags]
```
