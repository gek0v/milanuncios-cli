## milanuncios watch add ad

Watch a specific ad listing for price drops and removal

```
milanuncios watch add ad <id-or-url> [flags]
```

### Options

```
  -h, --help              help for ad
      --interval string   check interval (e.g. 5m, 300s, 1h) (default "5m")
      --name string       friendly name for this watch
```
